Print & Cut Flashcards

Turn an Anki export into a printable, cuttable sheet — fronts and backs aligned for double-sided printing, with sorting labels in the card corners.

1 · Card data
In Anki: Browse → select notes → Notes → Export Notes → Notes in Plain Text. Paste the whole file here, header lines and all.
Anki exports often begin with #notetype / #deck columns — those are detected and skipped automatically.

3 · Text
Sizes are true print points. Tibetan and other stacked scripts usually want a larger size and looser line spacing than Latin text.
Any font installed on this computer, by name. Leave blank for the built-in Noto stack (Tibetan, Chinese, Hebrew, Devanagari, Latin).
4 · Double-siding
Use grouped order for a single-sided printer: print the front half, reload the stack, print the back half.
5 · Corner labels
Small text in each card's corners, applied to every card — deck or series names, so cut cards can be re-sorted. Tokens: {n} running number, {total} deck size, {col:3} the text of column 3 (handy if a field already holds part of speech). For labels on individual cards, use the per-card panel beside the preview.
In the print dialog: scale 100% (not “fit to page”), margins Default, and headers & footers off — otherwise the grid shifts and the backs stop lining up.

A per-card label replaces the deck-wide label in that corner, for those cards only. Removing it lets the deck-wide one show through again. Tokens work here too: {n}, {total}, {col:3}.
Click a row to select; shift-click to select a range. Labels are saved in this browser and follow each card even if the deck is re-pasted or reordered.
